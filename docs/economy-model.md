# Экономическая модель Open Universe

Документ описывает, как устроена экономика проекта и почему она работает.
Проверяется **симуляцией в коде** (`server/crates/economy/src/market_sim.rs`),
а не только на бумаге.

## 1. Принципы

1. **Деньги не печатаются.** Внутри рынка кредиты только переходят между
   игроками. Симуляция проверяет это: `credits_delta = 0` за любой прогон.
2. **Ресурсы не возникают из воздуха.** Сырьё дают пояса астероидов и планеты
   (заданы в генерации мира). Всё остальное — переработка.
3. **Цены формируют игроки.** Нет «государственных» цен: есть стакан ордеров и
   встречные заявки.
4. **Дефицит поднимает цену, избыток — сдерживает.** Это проверено тестами.

## 2. Производственная цепочка

```
руда ──┐
       ├─► металл ──┐
лёд ───┘            ├─► сплав ──┬─► корпус ──┐
                    │           └─► электроника ─┤
кристалл ───────────┘                            └─► корабль
```

| Ступень | Входы | Выход | Смысл |
|---|---|---|---|
| выплавка металла | 2 руды | 1 металл | базовая переработка |
| перегонка топлива | 2 льда | 1 топливо | расходник |
| выплавка сплава | 2 металла + 1 кристалл | 1 сплав | средняя ступень |
| сборка электроники | 2 кристалла + 1 сплав | 1 электроника | сложный компонент |
| штамповка корпуса | 3 сплава | 1 корпус | конструктив |
| сборка двигателя | 2 сплава + 1 электроника | 1 двигатель | конструктив |
| сборка корабля | 1 корпус + 2 двигателя + 2 электроники | 1 корабль | конечный продукт |

Себестоимость растёт с каждой ступенью, поэтому цена корабля кратно выше руды.

## 3. Роли игроков (проверено симуляцией)

| Роль | Что делает | Источник дохода |
|---|---|---|
| **Добытчик** | добывает сырьё | продажа руды/льда/кристаллов |
| **Промышленник** | покупает сырьё, перерабатывает | продажа металла, сплава, кораблей |
| **Потребитель** | покупает и расходует продукт | сгорает (двигатели, топливо) |

Симуляция запускает виртуальных агентов этих ролей и смотрит на рынок.

## 4. Что показала симуляция

Прогон: 4 добытчика, 2 промышленника, 6 потребителей, 200 тиков.

```
сделок всего: объём 945
цена: min 7, max 65, VWAP 25
активных тиков: 192 из 200 (96%)
проверка денег: создано/сожжено кредитов = 0
```

**Первая версия рынка «замирала»**: агенты держали цены неизменными, сделок не
было, объём падал до нуля. Решение — адаптация цен: если тик прошёл без сделок,
продавцы постепенно уступают, покупатели поднимают ставку. После этого рынок
активен в 96% тиков.

### Сценарии

| Сценарий | Результат |
|---|---|
| Сбалансированная экономика | VWAP 25, живые 96% тиков |
| **Дефицит** (мало добытчиков, много потребителей) | цена держится/растёт |
| **Избыток** (много сырья, мало потребителей) | цена падает, VWAP 10 |
| **Дорогая переработка** | цена продукта растёт, объём падает |

## 5. Механики, которые защищают экономику

- **Эскроу товара**: при выставлении продажи предметы списываются сразу —
  нельзя продать то, чего нет.
- **Нельзя потратить чужие деньги**: покупатель проверяется по балансу.
- **Приоритет исполнения**: цена → время → id. Порядок однозначен, поэтому
  сделки воспроизводимы (важно для античита и разбора жалоб).
- **Рынки изолированы по системам**: цена в системе A не влияет на систему B.
  Торговля между системами — это логистика (перевозка груза), а не телепорт.
- **Налог территории**: владелец зоны берёт до 25% с оборота — стимул воевать
  за торговые пути (см. `crates/combat`).
