# План: интерфейс и игровое меню в духе Dual Universe

Документ описывает, как мы приводим интерфейс Open Universe к виду Dual
Universe (DU): что уже сделано, чего не хватает и в каком порядке это
реализуем и визуализируем. Сверка идёт с интерфейсом DU, который помним и
описываем ниже (игра остановлена 27.08.2025, поэтому сверка — по зафиксированному
опыту, а не по живому клиенту).

## 1. Как устроен интерфейс в Dual Universe (сверка)

DU — «песочница» с постоянно видимым HUD и набором открываемых окон. Ключевые
элементы, которые задают узнаваемый стиль:

| Элемент DU | Что это | Место |
|---|---|---|
| Игровой HUD | Прицел, компас (heading tape), телеметрия, топливо/энергия | всегда на экране |
| Радар / мини-карта | Круглый радар, метки тел, игроков, территорий | правый низ |
| Чат | Каналы (локальный/глобальный/организация), лента + строка ввода | левый низ |
| Лог событий / уведомления | Всплывающие тосты и лог (добыча, торговля, бой) | правый верх |
| Хотбар | Слоты под инструменты/модули | низ по центру |
| Панель-док окон | Ряд кнопок, открывающих окна, и навигация по ним | низ (док) |
| Инвентарь / контейнер | Сетка предметов, объём и масса, контейнеры слева | окно |
| Рынок / биржа | Стакан заявок, покупка/продажа, поиск, объёмы | окно |
| Производство / Industry | Рецепты, схема, очередь производства | окно |
| Карта территории | Карта зон и тел, метки, зум | окно |
| Дерево талантов | Узлы-навыки, ветки, очки | окно |
| Организация | Состав, ранги, налоги, дипломатия | окно |
| Строительство / шаблоны | Палитра, кисть, выделение, чертежи | режим + окно |
| Скрипты / programming board | Редактор Lua, привязка к объекту, вывод | окно |
| Настройки | Графика, звук, управление, переназначение клавиш | окно |

**Стиль DU:** тёмные полупрозрачные панели, холодные голубые/бирюзовые
акценты, тонкие линии, крупные заголовки, иконки, скруглённые углы, плавное
появление окон. Мы уже используем близкую палитру (`GlassPanel`, акцентные
линии) — задача довести её до единого языка.

## 2. Что уже есть в Open Universe

Реализовано (видно в игре):

- Постоянный HUD: прицел, компас, мини-карта, статусы (высота/координаты/связь/
  пинг), панели территории/боя/корабля, хотбар, подсказка управления.
- Стартовое меню: позывной (персонаж) + выбор сервера (список/ручной адрес).
- Пауза-меню (ESC): продолжить, настройки, отлучиться.
- Окна: рынок (M), скрипты (L), мастерская (K), организация (O), персонаж и
  таланты (P), воксели (V), палитра строительства (B).
- Чат (Enter/Tab): локальный/глобальный/организация.
- Обучение (tutorial): пошаговая панель, отключение в паузе.

## 3. Чего не хватает до «как в DU»

1. **Единая панель-док окон** — открытие всех окон из одного ряда кнопок и
   переключение между ними (сейчас — только «горячие» клавиши).
2. **Полноценное окно инвентаря/контейнера** — сетка предметов, объём и масса,
   перенос между трюмом и базой (сейчас только полоса загрузки трюма в HUD).
3. **Окно производства (crafting)** — рецепты, схема, очередь (сейчас есть
   только автокрафт в тестах).
4. **Окно карты** — территории и тела системы, метки, зум (сейчас миникарта в HUD).
5. **Дерево талантов** — визуальные ветки/узлы вместо списка.
6. **Список контактов и онлайн-игроков** — присутствие, приглашения.
7. **Лог событий и уведомления** — тосты и прокручиваемый лог.
8. **Настройки** — графика, звук, управление; переназначение клавиш.
9. **Единый визуальный стиль** — иконки, скруглённые углы, анимации, единые
   отступы и типографика всех окон.

## 4. Порядок реализации (задачи в плане, фаза 11)

1. Единая панель-док окон (навигация) — фундамент.
2. Окно инвентаря/контейнера.
3. Окно производства (crafting).
4. Окно карты.
5. Дерево талантов.
6. Контакты / онлайн-игроки.
7. Лог событий и уведомления.
8. Настройки: графика/звук/управление, keybinds.
9. Единый визуальный стиль и полировка.

## 5. Правило соответствия

Фаза 11 в `plan.json`/`data.js`/`plan.md` должна совпадать с тем, что реально
видно в игре: «готово» — только если экран/окно открывается и работает в
собранном клиенте (проверка на втором ПК, `tools/capture.ps1 -Preset menus`).
