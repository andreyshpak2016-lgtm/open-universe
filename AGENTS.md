# Правила разработки Open Universe

Короткий свод обязательных правил для агентов и людей. Если правило нарушает
сборку или публикацию — публикацию не делаем.

## 1. Сначала проверить UE-клиент, потом публиковать

**Правило:** перед любой публикацией (тег, релиз, обновление сайта) обязательно
запустить UE-клиент и убедиться, что он работает.

- Запуск теста: `powershell -ExecutionPolicy Bypass -File tools/test-ue.ps1`.
- Тест запускает игру, делает скриншот в `shots/ue-menu.png` и проверяет по логу
  ключевые признаки: карта загружена, GameMode активен, планета построена,
  меню рисуется.
- Если тест не прошёл — **сначала чиним проблему**, и только потом публикуем.
- Скриншоты (`shots/*.png`) — доказательство проверки; храним их вместе с
  задачей.

## 2. Авто-подключение для тестов

Ручные клики в UE-тестах ненадёжны (окно может не получить фокус). Поэтому для
тестов есть авто-подключение:

- Ключ `-OUAutoConnect` — меню само перебирает серверы из списка и
  подключается к **первому доступному**.
- `-OUName=Имя` — задаёт позывной пилота.
- Пример: `UnrealEditor.exe <uproject> -game -OUAutoConnect -OUName=TestPilot`.
- Тест `tools/test-ue.ps1` умеет поднимать Rust-сервер (`ou-netd`) и запускать
  клиент с авто-подключением, чтобы проверить связку клиент↔сервер целиком.

## 3. Проверка «сервер + клиент» (health)

- `tools/health.ps1` → `status.json` (сервер, клиент, симуляция, появление на
  планете). Публикуется на сайте и в лаунчере.
- Workflow `.github/workflows/health.yml` гоняет это каждые 30 минут.

## 4. Порядок выпуска

1. `cargo test --workspace` — зелёные тесты ядра.
2. `tools/build-client.ps1` — клиент собирается без ошибок.
3. `tools/test-ue.ps1` — UE-клиент реально запускается: показывает меню,
   подключается к серверу, ставит корабль на планету, строит базу. Скриншот —
   в `shots/ue.png`.
4. `tools/package-game.ps1` — пересобрать standalone-игру (иначе установщик
   останется старым, без последних изменений клиента!).
5. `tools/health.ps1` — статус сервер+клиент → `status.json`.
6. Только теперь: `tools/release.ps1 -Version X.Y.Z -Publish`.

**Важно:** шаг 4 (упаковка игры) обязателен перед релизом. Установщик игры
собирается из `client/Packaged/Windows`, и если не пересобрать игру, игроки
получат старый клиент.

## 5. Мелочи

- PowerShell-скрипты инструментов — UTF-8 с BOM; `.bat` — CP866.
- Временные скрипты в `%TEMP%\opencode` — только ASCII (кириллица ломает парсер).
- Текст в `.iss`/`.bat`/скриптах не должен ломать кодировку.
