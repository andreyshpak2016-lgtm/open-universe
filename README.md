# Open Universe

Сайт-витрина и план разработки MMO-песочницы **Open Universe** (в духе *Dual Universe*).

**Репозиторий:** https://github.com/andreyshpak2016-lgtm/open-universe
**Скачать (Releases):** https://github.com/andreyshpak2016-lgtm/open-universe/releases

- `index.html` — сайт (план + живой прогресс, галерея космоса, раздел «Технологии»)
- `report.html` — отчёт о разработке со скриншотами движка
- `styles.css`, `app.js` — оформление и логика рендера плана
- `plan.md` — план разработки (человекочитаемый)
- `plan.json` — тот же план в машиночитаемом виде
- `data.js` — копия `plan.json` для работы сайта при открытии файла напрямую (`file://`)
- `assets/*.jpg` — фото NASA (public domain): туманность Киля (JWST), чёрная дыра с джетом, астероид Гаспра, Земля (Blue Marble)
- `assets/render-*.png` — кадры собственного рендерера (трассировка лучей): корабль, чёрная дыра, астероиды, мир из симуляции, анимация, воксельные планеты, копание
- `assets/*.svg` — векторные сцены и иконки (логотип-фавикон, запасной арт)
- `assets/architecture.svg` — схема архитектуры (клиент ↔ сервер ↔ БД)
- `assets/er-data.svg` — ER-диаграмма данных (таблицы и связи)
- `assets/seq-frame.svg` — sequence-диаграмма одного сетевого кадра
- `docs/adr-0001-engine.md` — решение о выборе движка (Unreal Engine 5) и стека
- `client/` — каркас клиента на UE5 (C++): floating origin, сеть, корабль, воксельные планеты
- `server/` — рабочее серверное ядро на Rust (protocol, sim, server, client)

## Раздел «Архитектура» на сайте

Раздел состоит из вкладок:

1. **Слои системы** — статическая схема слоёв.
2. **Слои — интерактив** — карточки слоёв: наведение и клик раскрывают компоненты.
3. **ER-диаграмма данных** — статичная ER-схема (SVG).
4. **ER-схема — интерактив** — клик по таблице подсвечивает только её связи, справа
   открывается карточка с полями и переходами по связанным таблицам.
5. **Sequence одного кадра** — цикл «ввод → сервер → отклик».

Модель данных и связи для интерактива заданы в `app.js` (`ER_TABLES`, `ER_LINKS`).

## Как открыть

Просто откройте `index.html` в браузере — двойным кликом. Локальный сервер не нужен.

## Версии и релизы

Релизы публикуются на https://github.com/andreyshpak2016-lgtm/open-universe/releases

Два способа выпустить новую версию:

1. **Тег — и CI всё сделает сам:**
   ```bash
   git tag v0.4.0 && git push origin v0.4.0
   ```
   GitHub Actions прогонит тесты, соберёт все бинарники и приложит архив к релизу.

2. **Локально, одной командой:**
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools/publish.ps1 -Version 0.4.0
   ```

Сайт (раздел «Скачать») подтягивает данные последнего релиза через GitHub API.

## Движок и рендер

По ADR-0001 клиент — Unreal Engine 5. Пока UE не установлен, есть рабочий
**рендерер на Rust** (`crates/render`): настоящая трассировка лучей на CPU.

```bash
cargo run -p ou-render --release -- all 1280 720
#  ship · blackhole · asteroids  → три PNG-кадра
cargo run -p ou-render --release -- voxel 900 506   # воксельная планета
cargo run -p ou-render --release -- dig 640 360     # копание (до/после)
cargo run -p ou-sim --bin ou-landing-demo           # посадка на поверхность
```

### Рендер по сети (живой мир с сервера)

```bash
# терминал 1: сервер
cargo run -p ou-server --bin ou-netd -- 127.0.0.1:7777 10
# терминал 2: клиент рисует мир, что пришёл по UDP
cargo run -p ou-render --release --bin ou-netrender -- 127.0.0.1:7777 8 4
# → 1 baseline + 236 дельт → 4 кадра в render-net.png
```

Он рендерит тот же мир (планеты, корабли, астероиды, чёрные дыры), что
описывает сервер. Компоненты — камера, floating origin, сфера-планета, блочные
конструкции, процедурный шум — переносятся в UE5 один-к-одному.

## Серверное ядро (Rust)

В `server/` лежит рабочее ядро единого шарда: детерминированная симуляция,
бинарный протокол, UDP-транспорт, пространственный индекс, tick loop, interest
management и генерация мира.

```bash
cd server
cargo test --workspace                  # 58 тестов
cargo run -p ou-server                  # демо interest management и дельт
cargo run -p ou-client                  # демо предсказания и реконсиляции
cargo run -p ou-sim --bin ou-worldgen   # генерация звёздных систем
cargo run -p ou-shard --bin ou-shard-demo      # шардирование и миграции
cargo run -p ou-server --bin ou-persist-demo   # персистентность мира

# реальный UDP-обмен (в двух терминалах):
cargo run -p ou-server --bin ou-netd -- 127.0.0.1:7777 10
cargo run -p ou-client --bin ou-netclient -- 127.0.0.1:7777 8
```

Подробности — в `server/README.md`.

## Как менять план и прогресс

Статусы задач задаются в `data.js` (и дублируются в `plan.json` / `plan.md`):

| status        | Значение  |
|---------------|-----------|
| `done`        | Готово    |
| `in_progress` | В работе  |
| `todo`        | В планах  |

Общий процент и проценты фаз считаются автоматически:
`(готовые + 0.5 × в работе) / всего`.

Ключи фаз: `p0`…`p10`, описание — см. `plan.md`.
