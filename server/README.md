# Open Universe — серверное ядро (Rust)

Реализация ядра единого шарда по плану проекта: детерминированная симуляция,
бинарный протокол, tick loop и interest management. Это **не заглушки** —
код собирается, покрыт тестами и запускается.

## Структура

```
server/
├─ Cargo.toml                  # workspace
└─ crates/
   ├─ protocol/                # бинарный сетевой протокол + квантование + framing
   ├─ sim/                     # детерминированная симуляция (кинематика, мир)
   ├─ server/                  # авторитетный tick loop + interest management
   └─ client/                  # headless-клиент: предсказание и реконсиляция
```

## Запуск

```bash
cd server
cargo test --workspace      # 17 тестов: детерминизм, протокол, netcode
cargo run -p ou-server      # демо: interest management и дельта-снимки
cargo run -p ou-client      # демо: предсказание и реконсиляция
```

### Что показывает `ou-server`

```
 tick |     видит |        id |     байт | дист.
----------------------------------------------------------
  220 |         1 |         1 |       29 | 2042
  240 |         2 |       1,2 |       65 | 1828
```

Пока игроки вне зоны видимости, клиент получает только пустую дельту + `ack`
(**29 байт**). Как только дистанция падает ниже радиуса интереса — появляется
вторая сущность (**65 байт**). Средний трафик демо — ~0.7 КБ/с на игрока.


## Ключевые решения

### Детерминизм
Сервер и клиент должны вычислять мир **бит-в-бит одинаково**, иначе предсказание
бесполезно. Поэтому:

- своя тригонометрия `det_sin`/`det_cos` (полином), без `libm`;
- только операции `+ - * /` и детерминированный `sqrt`;
- фиксированный `dt` (30 Гц), порядок перебора сущностей — `BTreeMap`;
- проверка через `World::checksum()` (FNV-1a по квантованному состоянию).

### Квантование и floating origin
Позиция передаётся как `i32` с масштабом `10_000` (0.1 мм), диапазон ±214 км
вокруг локального начала отсчёта. В паре с floating origin этого достаточно для
локальной зоны, а мир целиком описан «плавающими» началами.

### Дельта-репликация
Сервер помнит последнее отправленное состояние каждого игрока
(`Connection::last_sent`) и шлёт только изменившиеся сущности
(`states_equal` по точности провода). Первый пакет — `baseline`.

### Interest management
Каждый клиент видит сущности в радиусе `INTEREST_RADIUS` (2000 ед.) от своей.
Радиус вынесен в константу и станет настраиваемым по типу зоны.

## Тесты (17)

| Крейт | Что проверяет |
|---|---|
| `protocol` | квантование позиций, round-trip всех сообщений, framing, отказ на обрезанном пакете |
| `sim` | точность тригонометрии, приведение углов, разгон по тяге, инерция+демпфирование, детерминизм (одинаковый ввод → одинаковая сумма) |
| `server` | видимость соседей, сокрытие далёких, пустая дельта без изменений, репликация движения |
| `client` | предсказание совпадает при идеальной сети, реконсиляция устраняет расхождение |
