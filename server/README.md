# Open Universe — серверное ядро (Rust)

Реализация ядра единого шарда по плану проекта: детерминированная симуляция,
бинарный протокол, UDP-транспорт, пространственный индекс, tick loop, interest
management и генерация мира. Код собирается, покрыт тестами и запускается.

## Структура

```
server/
├─ Cargo.toml                  # workspace
└─ crates/
   ├─ protocol/                # бинарный протокол + квантование + framing
   ├─ sim/                     # детерминированная симуляция + генерация мира
   ├─ spatial/                 # пространственный индекс (uniform grid)
   ├─ net/                     # UDP-транспорт, сессии, batching
   ├─ server/                  # авторитетный tick loop + interest management
   └─ client/                  # клиент: предсказание и реконсиляция
```

## Запуск

```bash
cd server
cargo test --workspace                  # 33 теста
cargo run -p ou-server                  # демо interest management и дельт
cargo run -p ou-client                  # демо предсказания и реконсиляции
cargo run -p ou-sim --bin ou-worldgen   # генерация звёздных систем

# реальный UDP-обмен (два терминала):
cargo run -p ou-server --bin ou-netd -- 127.0.0.1:7777 10
cargo run -p ou-client --bin ou-netclient -- 127.0.0.1:7777 8
```

### Реальный UDP (проверено)

Сервер `ou-netd` за 5 секунд: **149 тиков** (ровно 30 Гц), **244 снапшота**,
2 клиента, средний исходящий трафик **≈202 байта/тик**. Клиент отправлял 119
кадров, реконсиляция давала максимальную коррекцию **0.006 у.е.** при ровном
соединении (то есть предсказание почти идеально) и 0.000 в идеальном случае.

## Ключевые решения

### Детерминизм
Сервер и клиент вычисляют мир **бит-в-бит одинаково**:

- своя тригонометрия `det_sin`/`det_cos` (полином), без `libm`;
- только `+ - * /` и детерминированный `sqrt`;
- фиксированный `dt` (30 Гц), порядок перебора — `BTreeMap`;
- собственный ГПСЧ (SplitMix64) для генерации мира — воспроизводимо из семени;
- проверка через `World::checksum()` (FNV-1a).

### Квантование и floating origin
Позиция передаётся как `i32` с масштабом `10_000` (0.1 мм), ±214 км вокруг
локального начала. С floating origin этого хватает на локальную зону.

### Пространственный индекс
`ou-spatial` — равномерная сетка. Interest management обходит только ячейки,
пересекающие сферу запроса, а не весь мир. Результат всегда отсортирован по
`NetId` (детерминизм). Тест `matches_brute_force_on_random_layout` проверяет
эквивалентность наивному перебору на 500 телах и разных радиусах.

### Дельта-репликация и интерес
Сервер помнит последнее отправленное состояние каждого игрока и шлёт только
изменившиеся сущности; первый пакет — `baseline`. Пустая дельта + `ack` вне
зоны видимости — 29 байт.

### UDP-транспорт
`ou-net` добавляет поверх протокола: токен сессии (отсекает мусор и наивную
подмену адреса), очередь исходящих пакетов с батчингом (`flush`), отбрасывание
повреждённых дейтаграмм. Транспорт не влияет на детерминизм: привязка идёт к
номерам кадров и тиков, а не к порядку доставки.

## Тесты (33)

| Крейт | Что проверяет |
|---|---|
| `protocol` | квантование, round-trip сообщений, framing, отказ на обрезанном пакете |
| `sim` | тригонометрия, разгон, инерция, детерминизм, воспроизводимость ГПСЧ, генерация систем, орбиты |
| `spatial` | поиск соседей, сортировка, перемещение между ячейками, границы радиуса, сверка с полным перебором |
| `net` | round-trip пакета с токеном, отказ чужого/битого пакета, **реальный UDP-обмен по loopback** |
| `server` | видимость соседей, сокрытие далёких, пустая дельта, репликация движения |
| `client` | предсказание при идеальной сети, реконсиляция устраняет расхождение |
