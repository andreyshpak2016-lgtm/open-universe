# Open Universe — план разработки

**Open Universe** — это MMO-песочница в открытом космосе в духе *Dual Universe*:
единый непрерывный мир (single-shard), воксельная постройка, полностью
игрок-управляемая экономика, программируемые конструкции и территориальные войны.

> Цель: дать игрокам один общий живой космос, где всё — корабли, станции, города,
> экономика и законы — создаётся самими игроками.

- **Статус проекта:** Pre-Alpha (концепт + инфраструктура)
- **Общий прогресс:** считается автоматически на сайте (`index.html`)
- **Обновлено:** 2026-11-14

---

## Важно: как мы считаем прогресс

Пометка **«готово»** ставится только тому, что **игрок реально видит в игре** —
через подключённый UE5-клиент и живой сервер (`ou-netd`). Если система написана и
проходит тесты, но **к игре не подключена** (офлайн-демо, библиотека), это
**«в работе»**, а не «готово». Это правило появилось после ревизии: раньше план
отмечал готовым то, что жило лишь в тестах.

| Что видит игрок в игре сейчас | Состояние |
|---|---|
| Полёт корабля, посадка, гравитация планет | ✅ готово |
| Пеший персонаж, вид от первого лица | ✅ готово |
| Общий ландшафт планеты (сервер = клиент, бит-в-бит) | ✅ готово |
| Землеподобный рельеф (зоны, камень на склонах, детали) | ✅ готово |
| Стартовый комплекс: площадка, лестницы, постройки | ✅ готово |
| Копание грунта (ЛКМ, сервер-авторитетно, воксельные ямы) | ✅ готово |
| Руда слоями по глубине (руда/лёд/кристалл/металл) | ✅ готово |
| Бой: щит/броня, смерть, дроны-цели | ✅ готово |
| Строительство: ставить/удалять/красить с призраком блока | ✅ готово |

| Меню ESC: продолжить / настройки / отлучиться | ✅ готово |

## 1. Видение и ключевые столпы

| Столп | Описание |
|---|---|
| Единый шард | Один непрерывный мир для всех игроков, без «серверов-клонов» |
| Воксель без границ | Строительство из вокселей: от ручного инструмента до целых городов |
| Игрок-экономика | Ресурсы, производство, рынки и цены формируют сами игроки |
| Программируемость | Встроенный скриптинг (Lua-подобный) для автопилотов, турелей, логики |
| Территории и война | Захват, удержание и защита зон, орбитальные конфликты |
| Персистентность | Мир живёт 24/7, всё построенное сохраняется навсегда |

## 2. Целевая платформа и технологии

- **Клиент:** Unreal Engine 5 (C++) — решено в `docs/adr-0001-engine.md`
- **Сервер:** Rust (детерминированная симуляция, свои тригонометрия и физика)
- **Рендер:** воксельный рельеф планет, общий с сервером; атмосферы, скайбокс
- **Сеть:** UDP + бинарные дельты, репликация интересов (interest management)
- **БД:** версионированные снимки мира (атомарная запись, восстановление)
